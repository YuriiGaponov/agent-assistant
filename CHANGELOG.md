# Changelog

## [1.0]

### Added
#### агент
- в состоянии агента сохраняется id запроса и id пользователя
#### индекс
- при добавлении в индекс каждый документ получает уникальный id
- в метаданные документа включены:
    - модель эмбеддингов 
    - метаданные файла-источника
- реализован механизм **манифеста индекса**: при повторном запуске приложения в индекс добавляются только данные из новых или изменённых файлов-источников
#### логирование
- логирование шагов работы графа агента
#### общее
- механизм graceful shutdown - безопасное закрытие подключений к БД при остановке приложения

### Fixed
- логика агента не зависит от реализации менеджера LLM
- время инициализации коллекции сократилось на 19,47%
